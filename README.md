# Star Wars Blog

¡Bienvenido al **Star Wars Blog**! 🚀  
Un proyecto desarrollado con React que utiliza una API externa para mostrar información del universo de Star Wars. Incluye manejo de estado global, hooks, rutas y más.

## Características ⚙️

- **Consumo de API externa**: Llamadas a la API pública de Star Wars (SWAPI) para obtener datos sobre personajes, planetas y naves espaciales.
- **Gestión de estado global**: Implementación de Context API y Flux para centralizar el manejo de datos.
- **Hooks modernos de React**: Uso de `useState`, `useEffect` y `useContext` para manejar el ciclo de vida y los estados del componente.
- **Navegación con React Router DOM**: Rutas dinámicas para navegar entre páginas como personajes, planetas o detalles específicos.

## Tecnologías utilizadas 🛠️

- **React**: Librería principal para construir la interfaz de usuario.
- **Context API + Flux**: Para la gestión del estado global.
- **React Router DOM**: Para manejar la navegación entre rutas.
- **Bootstrap 5**: Estilizado responsivo y componentes prediseñados.
- **Fetch API**: Para realizar las peticiones a la API de Star Wars.
### Requirements:
- Make sure you are using node version 10

1. Install the packages:
```
$ npm install
```
2. Create a .env file:
```
$ cp .env.example .env
```
3. Start coding! and the webpack dev server with live reload, for windows, mac, linux or Gitpod:

```bash
$ npm run start
```
